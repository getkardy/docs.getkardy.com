---
title: Live view
description: Follow recent loyalty activity layered over an interactive colour globe.
---

**Where:** Merchant workspace → **Activity → Live**, or **Overview → View live**.
Available to Owners and Managers with the required programme access.

## See your store network

Choose **Fullscreen** to expand the globe and activity feed together. Use
**Exit fullscreen** or Escape to return. Browsers without native fullscreen use
an expanded-window view. The feed includes member avatars; the store panel is
height-limited so it does not cover recent activity.

The 3D globe uses blue oceans and green land, with a distinct marker colour for
each store. A scrollable activity panel floats over the map in **Activity → Live**.
Select a store in the legend or
a location in the activity feed to focus it. Pins use store coordinates;
approximate locations are labelled.

Drag the globe to turn it, use **+ / −** to zoom, or use **2D / 3D** to change
the projection. **Reset globe** returns to the world view. Arrow keys pan the
focused map; on touch screens, use two fingers to move it. Hold Command or Ctrl
while scrolling to zoom without interrupting normal page scrolling.

The feed shows the **latest ten recorded events**. The snapshot above it breaks
those events into stamps, redemptions and scans. These are counts within the
displayed feed, not all-time totals or the number of people currently online.

## Follow the activity

Live view checks for a new event every **15 seconds while the page is visible**.
It pauses in a hidden tab and checks again when you return. Use **Refresh** to
check manually. The status reports the last check or a connection failure;
an error must not be interpreted as no new activity.

Choose the **List view** tab for searchable history, or **View activity** beside an
event to open [Activities](/features/activities) filtered to that member.

<Warning>
  Pins represent **stores, not customer positions**. Kardy does not use this
  page to track visitors' GPS positions, website sessions or online presence. A
  new record can appear after the next successful check; this is not an
  instantaneous event stream.
</Warning>

Demo mode uses labelled fictional snapshots, not real customer events.
Live view is available within the workspace, not the landing-page bento.
Keep signed-in workspace displays private;
the feed can contain member and staff names.
