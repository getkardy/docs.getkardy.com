# Landing wallet parity

`wallet-drift.svg` is the unmodified output of the app's
`consumers/src/lib/card-artwork.ts` for Drift, primary `#42001C`, secondary
`#AF79F3`. The documentation card follows `landing-card.tsx` and its stylesheet:
Sunday wordmark, ten heart slots, coffee reward at ten, seven earned stamps,
white stamp panel and a sample QR. Never use a real member QR in illustrations.

The shared docs phone in `feature-illustration.jsx` follows the landing site's
`LandingPassDemo` 324 × 668 shell scaled to 220px wide. The install walkthrough
uses the same proportions at 208px wide, including matching corner radii.
Browser-wallet navigation is Wallet / Places / Rewards / Activity.

Keep the neutral documentation stage and accurate platform-specific native
wallet passes; native passes are not the same UI as the Kardy browser wallet.
