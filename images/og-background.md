# Documentation share background

`og-background.png` is a 1200 × 630 render of the app's `SocialProductArt` Safari
dashboard, using fictional totals and a light neutral/lilac background. The illustration
is deliberately subdued so Mintlify's per-page title, description and current documentation
logo remain readable. Configured through `docs.json` → `thumbnails.background`.

Do not replace it with a fixed full-image OG override: that would remove the unique
page titles generated by Mintlify. No account data or live membership QR is included.
