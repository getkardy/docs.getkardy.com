# Account avatar previews

These PNGs are static renders of the app's `GradientAvatar` from `@outpacelabs/avatars` 0.6.0 (MIT), using the same `defaultAvatarSeed(name)` and AccountAvatar palette: `#C9F269`, `#BFD8FF`, `#F1D4C3`, `#D9F0E4`, `#DED5F5`.

Rendered at 32 CSS pixels with a 3× pixel density and `p3` enabled. Names are fictional example records. Re-render from the app component if its avatar system changes; do not substitute initials or hand-made gradients.
